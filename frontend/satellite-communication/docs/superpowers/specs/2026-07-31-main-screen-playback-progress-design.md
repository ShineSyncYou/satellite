# 主屏播放进度条与主副屏场景控件调整设计

## 目标

调整仿真主屏与参数副屏的顶部控制区：

- 主屏和副屏都移除运行期间的场景切换下拉菜单。
- 主屏增加可拖动的播放进度条。
- 主屏的播放/暂停、倍速和进度条组成一块完整的播放控制区。
- 副屏不增加进度条或新的播放控制，继续展示主屏同步的场景、时刻和速率。

## 范围

本次只修改：

- `frontend/satellite-communication/src/views/OperationsView.vue`
- `frontend/satellite-communication/src/views/MetricsScreenView.vue`

不修改场景库、仿真生成、Python 输出协议、Node API 和场景数据结构。

## 主屏布局

顶部工具栏保留：

- 返回首页
- 中国居中
- 打开参数副屏

删除“场景”文字和场景切换下拉框。

播放控制区包含：

- 播放/暂停按钮
- 倍速选择
- 当前仿真时间
- 可拖动进度条
- 总仿真时间

控件在宽屏下保持单行；空间不足时允许播放控制区整体换行，进度条优先占用剩余宽度。

## 主屏交互

Cesium `viewer.clock` 仍是播放状态和仿真时间的唯一真实来源。

- 点击播放/暂停：更新 `viewer.clock.shouldAnimate`。
- 修改倍速：更新 `viewer.clock.multiplier`。
- 拖动进度条：根据相对秒数设置 `viewer.clock.currentTime`。
- 拖动期间显示目标时间，提交后恢复由 Cesium 时钟驱动。
- 仿真循环回到开头后，进度条随现有时钟同步更新。

进度条范围为 `0` 到当前 bundle 的 `durationSeconds`。场景尚未加载完成或时长无效时禁用进度条。

## 副屏调整

副屏顶部删除场景标签和场景下拉框，保留：

- 当前场景、时刻和速率摘要
- 打开 3D 主屏按钮
- 主屏连接状态

副屏仍通过 URL 初始参数和现有 `BroadcastChannel` 消息加载、同步场景。移除下拉菜单不改变主屏向副屏发送场景变更消息的兼容逻辑。

## 状态与异常

- 无可运行场景时，沿用现有空状态提示。
- 场景加载期间禁用播放控件。
- 拖动值必须限制在 `0` 到场景总时长之间。
- 不新增副屏控制主屏的命令，避免引入本次需求之外的同步状态。

## 验证标准

1. `npm run build` 成功。
2. 主屏和副屏均不再显示场景切换下拉菜单。
3. 主屏播放/暂停和倍速功能保持正常。
4. 主屏进度条随仿真播放连续更新。
5. 拖动主屏进度条后，Cesium 场景、实体状态和副屏时刻同步到目标时间。
6. 副屏继续正确展示当前场景、时刻、速率和连接状态。
7. 窄屏下播放控制区不遮挡主要导航按钮。
